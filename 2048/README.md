# 🎮 C-games

A collection of beginner-friendly C++ games built as part of my programming fundamentals journey.  
This repository currently includes a simple implementation of the classic **2048 game**.

---

## 📌 Features
- Written in **C++** for clarity and practice with core programming concepts.
- Implements the **2048 sliding tile puzzle**.
- Score saving functionality with text files.
- Uses a lightweight graphics library (`cppgraphics`) for rendering.

---

## 🛠️ Setup Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/codesbymusab/C-games.git
   ```
2. Install and configure the `cppgraphics` library.
   - Copy all required resources to your **Public Documents** folder.
3. Compile the project:
   ```bash
   g++ main.cpp -o Cgames
   ```
4. Run the executable:
   ```bash
   ./Cgames
   ```
